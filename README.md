# Log Viewer

在线查看 Halo 运行日志

![](./images/preview.png)

## 使用

- 在 [Halo 应用市场](https://www.halo.run/store/apps/app-pcgkazpl) 或者 [Release](https://github.com/ruibaby/plugin-log-viewer/releases) 中下载并安装
- 进入概览 -> 日志页面即可查看日志

## 开发

```bash
git clone https://github.com/ruibaby/plugin-log-viewer && cd plugin-log-viewer
./gradlew haloServer
```
